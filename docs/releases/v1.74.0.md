# Perch v1.74.0

Team-room messages now queue one at a time per bot and confirm delivery only
when Claude acknowledges the matching post. Wrap-up reminders use their own
sequence numbers, retries retain attachments, and a persistent outbox preserves
queued work across restarts. Broadcasts complete when every recipient confirms.

Permission-card answers now use Claude's documented response format, fixing
prompts that remained open after Allow. The room distinguishes queued messages
from submissions awaiting acknowledgement.

Unreadable saved data is preserved, task saves refuse conflicting outside edits,
and writes use atomic replacement. Background terminals consume output reliably,
closed panes release caches, and hidden terminals release graphics resources.
Git-detail caching reduces repeated subprocess work; process timeouts also cover
blocked input and output. Font preferences and web-content packaging are fixed.

The repository includes architecture guidance, review findings, and regression
tests for future contributors.
