What changed

  • Trunk connects. Nested rows carried a 1px transparent border, so the trunk stopped 1px shy of each edge — a 2px gap at every junction. Drop the border on nested rows (they never showed a frame) and add it back as padding; the trunk now spans the whole box and touching rows meet.
  • Tick reaches the node. The horizontal tick grows 7px → 12px so it terminates at the spinner/dot instead of pointing into empty space.
  • Spinner sized as the node. 11px → 13px, flex-centered in its slot so it sits on the tick line rather than floating above it.
