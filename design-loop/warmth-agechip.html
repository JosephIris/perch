Age chip, dialled down

The green pill was making the age label compete with the dot for the same job. Four quieter cuts. Dot column is identical in all of them — uniform green for “your turn”, existing braille spinner for working, red for permission.

C0 · green pill (before)

Two signals shouting. The pill also invents a surface the sidebar doesn’t otherwise have.

C1 · brightness only

Zero hue. Fresh age is near-white and semibold, stale fades to 30%. Nothing new in the palette.

C2 · one green line

Only <2m gets the green, as text — no fill. Everything older is plain gray.

C3 · whole row recedes

Age stays gray; stale rows dim entirely, dot included. Fewest moving parts.

C4 · mono telemetry

10px mono numerals, brightness ramp. Feels like an instrument readout, not a badge.

C1 is the pick — it adds no color to a sidebar that already carries five state hues, and brightness alone is enough because the dot already says “your turn.” C3 is the most restrained but dims the dot too, which weakens the one signal you want kept. C2 is a decent middle if <2m deserves a nudge. C4 is handsome but mono here competes with the terminal’s voice.
