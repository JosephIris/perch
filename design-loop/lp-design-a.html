Field note 2. Perched above the work, one can simply... see it. Revolutionary.

Every agent, at a glance

perch reads each session through Claude Code's own hooks, not by scraping terminal output. So the sidebar always knows: working, done, or waiting on you, with the agent's actual question right on the row.

Finished agents wear their age, and the age cools as it sits. Eleven done rows become a triage order without reading a word.

Done with a tab? Click the moon. The agent exits politely, the transcript saves, and the tab folds into its project's Idle drawer. Click it later and it resumes where it left off.

Field note 3. The subject briefs its agent by pasting one screenshot instead of four paragraphs. Progress.

Brief it on a board

New in perch: every tab gets a board. Throw a screenshot, a file, a link, and a sentence onto it before you hand the task over.

perch turns all of it into something your agent can actually open: pasted images land in the repo, links are fetched and cached so the agent reads them offline, and every card becomes a path in one markdown file the agent is told about automatically.

Stop re-pasting context into every prompt. Stage it once, point every agent in the tab at it.

Built for Windows. On purpose.

Not a Mac app in a browser tab, not a port where Windows came last. WPF, WebView2, real Win11 Mica: perch sits next to Windows Terminal and the Settings app like it grew up there, because it did.

Yours, permanently

MIT licensed, source on GitHub. No account, no telemetry, no cloud between you and your agent. It can't be sunset out from under you.

Survives everything

Sessions save incrementally, so layout, names, and Claude conversations survive crashes, not just clean exits, and resume on the way back up.

Light on the machine

A workspace that watches agents shouldn't slow them down. perch idles at roughly zero background processes, and a test ceiling keeps it that way.

Verifiable builds

Store builds are signed on ingestion. GitHub releases carry provenance attestations you can check with one gh command.

Questions

Is it free?

Yes. MIT licensed, source on GitHub, no account, no telemetry decisions to agonize over.

Does it need Claude Code?

perch is built around Claude Code and speaks its hooks natively, but any shell or agent runs happily in a pane.

Microsoft Store or GitHub download?

Same app. The Store handles updates for you; the GitHub build updates itself. Switch whenever, your sessions and settings carry over.

How does it know what agents are doing?

A bundled perch CLI plus Claude Code hooks: the agent tells its pane what's happening. Nothing scrapes terminal output, and nothing leaves your machine.

Windows only?

Yes, Windows 10 and up, with proper Win11 polish. On a Mac, cmux has you covered. No hard feelings. (Speak for yourself. — M.G.)
