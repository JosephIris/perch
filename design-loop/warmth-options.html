“Your turn” warmth — five ways

Same data in every column. Working rows keep the existing braille spinner — untouched. Only the done (= agent handed the turn back) rows differ. Buckets: hot <2m · warm 2–10m · cool 10m–1h · cold >1h, all off the doneAtMs already being pushed.

A · Opacity decay

Dot fades green→hollow, title dims in step. Smoothest, most gradual.

B · Fill → ring

Binary: solid = fresh, hollow = stale. One hard edge, no in-between guessing.

C · Age chip carries it

Dots stay uniform. The timestamp is the signal — fresh gets a green pill.

D · Left-edge bar

Warmth lives in a 2px rail, dot column untouched. Reads as a margin scan.

E · Size decay

Dot shrinks with age, 9px→3px. Color constant, so it survives colorblindness.

A is the safest and most Fluent-native. C is the least invasive — zero change to the dot column, so it can't fight the existing state palette. E is the only one that doesn't lean on hue at all. D risks reading as the accent stripe the constitution rules out for sidebar selection. B is crisp but loses the “how stale” gradient.
