perch is a native Windows workspace for running Claude Code and friends across your projects. Watch every agent work, see what it changed, and take over in a real terminal when you want to.

Free and open source · Windows 10+

A live slice of the workspace: real components, fixture data. Spinners tick, the ages warm, the journal filters. Nothing here is a screenshot.

Every agent, in one place

perch reads each Claude Code session through its hooks, not by scraping the terminal, so the workspace always knows who's working, who's done, and who needs you. These are the app's real components, live.

Sessions know their state

Working, done, or waiting on you. The sidebar and the dashboard keep score, so you stop babysitting terminals.

See what it actually did

The inspector turns an agent session into a journal: filters, image previews, and the exact files it touched.

Boots are covered

While Claude Code starts, Monocle Guy holds the fort. The frosted glass lifts the moment your pane is ready.

Built Windows-first, and actually native

Most tools for running coding agents are Mac-first, or a cross-platform port where Windows is an afterthought. perch is the only agent workspace built on native Windows tech: WPF, WebView2, and real Win11 Mica. It sits next to Windows Terminal and the Settings app, not like a Mac app in a browser tab.

Questions

Is it free?

Yes. MIT licensed, source on GitHub, no account, no telemetry decisions to agonize over.

Does it need Claude Code?

perch is built around Claude Code and speaks its hooks natively, but any shell or agent runs happily in a pane.

Windows only?

Yes, Windows 10 and up, with proper Win11 polish. On a Mac, cmux has you covered.

How does it know what agents are doing?

A bundled perch CLI plus Claude Code hooks: the agent tells its pane what's happening. Nothing scrapes terminal output.
