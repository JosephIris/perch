A power tool for non‑power users.

perch is a Windows workspace for running Claude Code and friends across your projects. Watch every agent work, see what it changed, and take over in a real terminal when you want to.

Questions

Is it free?

Yes. MIT licensed, source on GitHub, no account, no telemetry decisions to agonize over.

Does it need Claude Code?

perch is built around Claude Code and speaks its hooks natively, but any shell or agent runs happily in a pane.

Windows only?

Yes, Windows 10 and up, with proper Win11 polish. On a Mac, cmux has you covered.

How does it know what agents are doing?

A bundled perch CLI plus Claude Code hooks: the agent tells its pane what's happening. Nothing scrapes terminal output.
